# Library (reference material, not plugins)

- `awesome-design-md/`: ~70 ready-made DESIGN.md files describing real brands' design systems (Apple, Stripe, Linear, Notion, Claude, ...), each with HTML previews. To use one: copy `awesome-design-md/<brand>/DESIGN.md` into a project root and tell Claude to follow it. Source: VoltAgent/awesome-design-md (MIT).
- `design-md-spec/`: Google's DESIGN.md format spec and philosophy (google-labs-code/design.md, Apache-2.0). Pair with the `stitch-design-md` plugin, which generates and extracts DESIGN.md files.
